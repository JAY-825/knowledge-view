# uniapp扫码跳转小程序与参数获取

# 扫码跳转微信小程序

# 配置普通二维码跳转规则

  • 在微信小程序管理后台为“扫普通链接二维码”配置规则：添加域名前缀（如 https://example.com/scan）、目标小程序页面路径（如 /pages/entry/index）、参数映射策略（将链接上的查询参数映射到小程序的 query）。
  • 规则生效后，用户扫一扫符合规则的普通二维码即可直接打开目标页面。

# 启动获取二维码参数

  • 在应用启动或进入时获取参数：
// app.js
App({
  onLaunch(options) {
    const { query } = options
  },
  onShow(options) {
    const { query } = options
  }
})

  • 在跳转目标页面获取参数（推荐）：
// 二维码配置跳转的页面
Page({
  onLoad(option) {
    // 微信小程序扫码跳转时，二维码参数在 option.q 中
    let q = decodeURIComponent(option.q)
    // 解析二维码参数
		const obj = this.urlParamParse(q)
  },
  methods: {
    urlParamParse(url){
      let obj = {}
      let str = url.slice(url.indexOf('?') + 1)
      let arr = str.split('&')
      for (let j = arr.length, i = 0; i < j; i++) {
        let arr_temp = arr[i].split('=')
        obj[arr_temp[0]] = arr_temp[1]
      }
      return obj
    }
  }
})

  • 普通二维码常见做法是将原始链接经参数名（如 q）传递，页面中 decodeURIComponent(query.q) 后自行解析。

# 注意事项

  • 普通二维码跳转须在后台完成“二维码规则”配置并发布，否则仅会打开 H5 或无法跳转至小程序。
  • query 中是否存在 q、url 等取决于你的映射策略；统一规范参数名并在服务端生成二维码时保持一致。
  • 解析后的链接再做业务参数校验与签名验证，避免伪造二维码导致越权。
  • 若小程序运行中再次通过扫码进入，可用 wx.onAppShow 或 wx.getEnterOptionsSync 获取最新参数。

# 扫码跳转支付宝小程序

# 配置普通二维码跳转规则

  • 在支付宝小程序控制台为“二维码跳转规则”配置域名前缀与目标页面路径，并设置参数映射（将链接查询参数透传到小程序页面的 query）。
  • 规则发布后，支付宝扫一扫匹配到规则的普通二维码即可打开目标页面。

# 启动获取二维码参数

支付宝获取二维码参数通常是在app.vue的onLaunch和onShow中获取，支付宝文档上写着在onLaunch中获取参数，但是在实际测试中，扫描普通二维码跳转时在onShow中也可获得获取参数。

注意：扫描普通二维码跳转时在目标页面是获取不到参数的，onload和onshow都无法拿到参数，只能在app.vue中获取。

  • 在应用启动或显示时读取参数：
// app.js
App({
  onLaunch(options) {
    // this.optionHandler(options)
  },
  onShow(options) {
    this.optionHandler(options)
  },
  methods: {
    // 支付宝扫码进入参数处理
    optionHandler(option){
      if(option.query && option.query.qrCode) {
        // 获取二维码参数
        let qrCode = urlParamParse(option.query.qrCode)
      }
    },
    urlParamParse(url){
      let obj = {}
      let str = url.slice(url.indexOf('?') + 1)
      let arr = str.split('&')
      for (let j = arr.length, i = 0; i < j; i++) {
        let arr_temp = arr[i].split('=')
        obj[arr_temp[0]] = arr_temp[1]
      }
      return obj
    }
  }
})

# 注意事项

  • 微信小程序获取二维码参数可在app.vue和目标页面中获取，支付宝小程序只能在app.vue中获取。
  • 微信小程序获取二维码参数时，app.vue参数在option.query.q中，页面参数在option.q中，需要自己解析参数。
  • 支付宝小程序获取二维码参数时，参数在option.query.qrCode中，需要自己解析参数。
  • 两者都可以通过启动参数的参数字段名判断或者启动场景值sence判断是否是扫码跳转。
