# package.json 学习文档

package.json 是 Node.js 与前端项目的包清单，描述项目的元信息、依赖、脚本、发布配置与生态工具集成。掌握其常用字段与最佳实践有助于规范项目与提升可维护性。

# 基本字段

  • name 包名（小写、无空格，建议使用短横线）
  • version 版本（遵循 SemVer：MAJOR.MINOR.PATCH）
  • description 简介
  • keywords 关键词数组
  • author、contributors 作者与贡献者
  • license 许可协议（如 MIT）
  • private 私有包（true 时禁止发布到 npm）
  • repository、bugs、homepage 仓库地址、问题反馈与主页
{
  "name": "example-app",
  "version": "1.0.0",
  "description": "示例应用",
  "private": true,
  "license": "MIT"
}

# 模块入口与类型

  • main CommonJS 入口文件（如 dist/index.cjs）
  • module ESM 入口（非标准，打包器约定）
  • type 包类型：module（默认 ESM）或 commonjs
  • exports 条件导出（推荐现代库使用）
  • types/typings TypeScript 类型入口
  • files 发布时包含的文件白名单
  • sideEffects 标记副作用文件（用于 Tree-Shaking）
{
  "type": "module",
  "main": "dist/index.cjs",
  "module": "dist/index.js",
  "types": "dist/index.d.ts",
  "exports": {
    ".": {
      "import": "./dist/index.js",
      "require": "./dist/index.cjs",
      "types": "./dist/index.d.ts"
    }
  },
  "files": ["dist", "README.md"],
  "sideEffects": ["dist/polyfill.js"]
}

# 依赖管理

  • dependencies 运行时依赖
  • devDependencies 开发依赖（构建、测试、Lint 等）
  • peerDependencies 同行依赖（由最终应用安装），用于插件与库对宿主版本的约束
  • peerDependenciesMeta 同行依赖的可选性标记
  • optionalDependencies 可选依赖（安装失败不报错）
  • overrides（npm）/resolutions（Yarn）依赖覆盖

版本范围建议：

  • ^1.2.3 允许小版本更新，保持 API 兼容
  • ~1.2.3 仅允许补丁更新
  • 锁版本用于应用，范围用于库（兼容更广）
{
  "dependencies": {
    "react": "^18.2.0"
  },
  "devDependencies": {
    "typescript": "^5.6.3",
    "vite": "^5.0.0"
  },
  "peerDependencies": {
    "react": ">=18",
    "react-dom": ">=18"
  },
  "peerDependenciesMeta": {
    "react-dom": { "optional": true }
  }
}

# 脚本（scripts）

  • 定义项目任务命令，使用 npm run <name> 或 pnpm run <name> 执行
  • 预设钩子：pre<name>、post<name>（前后置操作）
{
  "scripts": {
    "dev": "vite",
    "build": "tsc -p tsconfig.build.json && vite build",
    "test": "vitest run",
    "lint": "eslint .",
    "preview": "vite preview"
  }
}

# 发布与私有

  • private: true 禁止误发布
  • publishConfig 发布配置（如 access、registry、tag）
  • bin CLI 可执行映射（发布后自动链接到 node_modules/.bin）
{
  "private": false,
  "publishConfig": { "access": "public" },
  "bin": { "mycli": "dist/cli.js" }
}

# 运行环境与包管理器

  • engines 指定 Node 版本范围
  • packageManager 指明所用包管理器与版本（便于团队一致）
  • os/cpu 可限制平台
{
  "engines": { "node": ">=18" },
  "packageManager": "pnpm@9.10.0"
}

# 使用建议

  • 应用锁版本（package-lock.json/pnpm-lock.yaml）并启用 CI 安装的冻结模式
  • 库使用兼容范围（^ 或 >=），并通过 peerDependencies 约束宿主
  • 明确 type 与 exports，统一 ESM/CJS 的消费方式与类型入口
  • 开启脚本的前后置钩子构建流程，保证任务完整性
  • 使用 packageManager/engines 固定团队环境版本
  • 对外发布前使用 files 白名单并检查副作用标记 sideEffects

# 示例：应用型项目

{
  "name": "web-app",
  "version": "0.1.0",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "vue": "^3.5.0"
  },
  "devDependencies": {
    "vite": "^5.0.0",
    "eslint": "^9.0.0"
  }
}

# 示例：库型项目（带条件导出与类型）

{
  "name": "utils-lib",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "import": "./dist/index.js",
      "require": "./dist/index.cjs"
    },
    "./feature": {
      "types": "./dist/feature.d.ts",
      "import": "./dist/feature.js"
    }
  },
  "files": ["dist"],
  "sideEffects": false,
  "types": "dist/index.d.ts",
  "scripts": {
    "build": "tsc && rollup -c"
  },
  "peerDependencies": {
    "react": ">=18"
  }
}
