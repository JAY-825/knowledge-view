# class类

JavaScript 的 class 提供更直观的面向对象语法，但本质仍是基于原型链的封装与继承。理解构造流程、继承规则、私有元素、公有类字段以及静态成员与静态初始化代码块，有助于编写可维护的代码。

# 构造函数

  • 描述：constructor 是类的构造函数，用于初始化实例。在派生类中，必须先调用 super() 才能使用 this。
  • 语法：
class Point {
  constructor(x, y) {
    this.x = x;
    this.y = y;
  }

  length() {
    return Math.hypot(this.x, this.y);
  }
}

const p = new Point(3, 4);
p.length();

  • 规范要点：
    • 类声明存在暂时性死区；在声明之前访问会抛错。
    • 类方法默认不可枚举，定义在原型上；字段定义在实例上。
    • 未显式定义 constructor 时，基类提供空构造函数，派生类提供 constructor(...args) { super(...args) }。
    • 只能通过 new 调用类构造函数。
    • new.target 在构造时指向当前被 new 的构造器，可用于抽象基类防止直接实例化。
class Base {
  constructor() {
    if (new.target === Base) throw new Error('Base is abstract');
  }
}

class Impl extends Base {}
new Impl();

# extends继承

  • 描述：extends 建立原型链与构造链。实例的原型指向父类的原型，子类构造器的原型链也连接到父类构造器。
  • 语法：
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() { return this.name; }
}

class Dog extends Animal {
  constructor(name, age) {
    super(name);
    this.age = age;
  }
  speak() { return super.speak() + ' bark'; }
}

const d = new Dog('Buddy', 2);
d.speak();

  • 注意事项：
    • 在派生类构造函数中，访问 this 前必须先调用 super()。
    • super.method() 在实例方法中指向父类原型，在静态方法中指向父类构造器。
    • 可以使用表达式作为继承目标；若继承目标不是可构造对象会抛错。class A extends null {} 使 A.prototype.__proto__ === null。

# 私有元素

  • 描述：私有字段、私有方法、私有访问器使用 # 声明，仅在类的词法作用域内可访问。
  • 语法：
class Counter {
  #value = 0;
  #inc(step = 1) { this.#value += step; }
  get #double() { return this.#value * 2; }
  set #reset(v) { this.#value = v; }

  add(step) { this.#inc(step); }
  current() { return this.#double; }
}

const c = new Counter();
c.add(2);
c.current();

# 公有类字段

  • 描述：公有实例字段在类体内直接声明，作为实例的自有属性存在，初始化在构造流程中执行。
  • 语法：
class User {
  name = 'anonymous';
  tags = [];
  onClick = () => this.tags.push('clicked');

  constructor(name) {
    if (name) this.name = name;
  }
}

const u = new User('Jay');
u.onClick();

# static和静态初始化代码块

  • 描述：static 定义静态字段与静态方法，属于类本身。静态初始化代码块 static {} 用于执行一次性的类级初始化逻辑。
  • 语法：
class Registry {
  static items = new Map();
  static #seed = 0;

  static create(key) {
    const id = ++this.#seed;
    this.items.set(key, id);
    return id;
  }

  static {
    const defaults = ['a', 'b'];
    for (const k of defaults) this.items.set(k, 0);
  }
}

Registry.create('x');
