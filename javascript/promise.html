# Promise

Promise 用于表示一个异步操作最终的完成值或失败原因，使异步代码可以以可组合、可链式的方式组织。

# 介绍

  • 状态：pending（待定）、fulfilled（已兑现）、rejected（已拒绝）
  • 敲定（settled）：fulfilled 或 rejected 的统称
  • 解决（resolved）：表示 Promise 已经被锁定为与另一个 thenable 的最终状态一致；已解决并不一定已敲定
  • 链式：then/catch/finally 返回新的 Promise，可进行串联与错误传递
  • 作业队列：处理器在微任务队列中排队执行，保证一致的异步时序
  • 取消：Promise 本身不支持取消；可结合 AbortController 取消底层操作

# 构造函数

  • 语法：new Promise((resolve, reject) => { /* 执行器 */ })
  • 执行器同步执行；调用 resolve(value) 兑现，reject(reason) 拒绝
const p = new Promise((resolve, reject) => {
  setTimeout(() => resolve('ok'), 100)
})

# 静态属性

  • Promise.length：形参个数（2）
  • Promise.name：构造函数名（'Promise'）
  • Promise.prototype：原型对象

# 静态方法

  • Promise.resolve(value)：将值包装为已兑现的 Promise；若为 thenable，则等待其结果
  • Promise.reject(reason)：创建已拒绝的 Promise
  • Promise.all(iterable)：全部兑现才兑现；任意一个拒绝则立即拒绝
  • Promise.allSettled(iterable)：等待全部敲定，返回每项的状态与值/原因
  • Promise.race(iterable)：第一个敲定的结果作为整体结果
  • Promise.any(iterable)：第一个“兑现”的结果作为整体结果；若全部拒绝则抛 AggregateError
  • Promise.withResolvers()：返回 { promise, resolve, reject } 的便捷封装
const p1 = Promise.resolve(1)
const p2 = Promise.reject(new Error('fail'))
const all = Promise.all([p1, Promise.resolve(2)])
const settled = Promise.allSettled([p1, p2])
const fastest = Promise.race([
  new Promise(r => setTimeout(() => r('A'), 50)),
  new Promise(r => setTimeout(() => r('B'), 10)),
])
const firstAny = Promise.any([
  Promise.reject('x'),
  Promise.resolve('y'),
])
const { promise, resolve, reject } = Promise.withResolvers()
resolve('done')

# 实例属性

  • Promise.prototype.constructor：指回构造函数
  • Promise.prototype[Symbol.toStringTag]：默认 'Promise'

# 实例方法

  • then(onFulfilled?, onRejected?)：注册兑现/拒绝处理器，返回新的 Promise
  • catch(onRejected)：等价于 then(undefined, onRejected)
  • finally(onFinally)：在敲定后执行清理，不改变链路状态与值（除非抛错）

# 链式与错误传递规则

  • 若处理器返回 thenable，新 Promise 跟随其状态；返回非 thenable 则兑现为该值
  • 若处理器抛错，新 Promise 以该错误拒绝
  • 若未提供对应处理器，新 Promise 继承初始 Promise 的状态与值/原因
fetch('/api')
  .then(res => res.json())
  .then(data => data.items)
  .catch(err => { throw new Error('wrap: ' + err.message) })
  .finally(() => console.log('done'))

# 构造与取消底层操作（AbortController）

function request(url, { signal } = {}) {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest()
    xhr.open('GET', url)
    xhr.onload = () => resolve(xhr.responseText)
    xhr.onerror = () => reject(new Error('network'))
    xhr.send()
    if (signal) {
      const onAbort = () => { xhr.abort(); reject(new DOMException('Aborted', 'AbortError')) }
      signal.addEventListener('abort', onAbort, { once: true })
    }
  })
}

const controller = new AbortController()
request('/data', { signal: controller.signal })
  .then(text => console.log(text))
  .catch(err => console.error(err.name, err.message))
controller.abort()

# 并发组合

async function loadAll() {
  const [user, posts] = await Promise.all([
    fetch('/user').then(r => r.json()),
    fetch('/posts').then(r => r.json()),
  ])
  return { user, posts }
}

# 收集所有结果

const results = await Promise.allSettled([
  fetch('/a'),
  fetch('/b'),
])
for (const r of results) {
  if (r.status === 'fulfilled') console.log('value', r.value)
  else console.warn('reason', r.reason)
}
