# typeof与instanceof

typeof 与 instanceof 是 JavaScript 中常用的类型与归属检测工具。二者侧重不同：typeof 聚焦“值的基本类型”，instanceof 检查“对象的原型链归属”。

# 语法

typeof 表达式           // 返回一个字符串，描述基本类型或函数/对象
对象 instanceof 构造函数 // 返回布尔值，判断原型链上是否存在该构造函数的 prototype
1
2

# 描述

  • typeof 返回值可能为："undefined" | "boolean" | "number" | "string" | "symbol" | "bigint" | "function" | "object"
  • instanceof 的判断依据是：Ctor.prototype 是否出现在对象的 [[Prototype]] 链上
  • 二者覆盖面不同：
    • typeof 擅长区分原始类型与函数，但对对象细分（数组、正则、日期等）一律返回 object
    • instanceof 擅长判断某对象是否由特定构造器生成或继承其原型，但对原始值不适用

# 示例

// typeof：原始类型与函数
typeof 1;               // 'number'
typeof 'hi';            // 'string'
typeof true;            // 'boolean'
typeof undefined;       // 'undefined'
typeof Symbol();        // 'symbol'
typeof 10n;             // 'bigint'
typeof function () {};  // 'function'

// 注意：历史遗留行为
typeof null;            // 'object'（不是 'null'）

// 对对象细分能力有限
typeof {};              // 'object'
typeof [];              // 'object'
typeof /re/;            // 'object'

// instanceof：原型链归属
[] instanceof Array;                 // true
new Date() instanceof Date;          // true
/abc/ instanceof RegExp;             // true
({}) instanceof Object;              // true

// 原始值与包装对象
'hi' instanceof String;              // false（字面量是原始值）
new String('hi') instanceof String;  // true（包装对象）

// 跨 iframe/realm 的陷阱：可能出现 false
// Array.isArray 更稳妥
Array.isArray([]);                   // true（跨上下文也可靠）

# 使用注意事项

  • typeof null === 'object' 是历史遗留行为；判断 null 请直接用 x === null
  • 判断数组、正则、日期等具体对象类型时，优先使用：
    • Array.isArray(value)
    • Object.prototype.toString.call(value) === '[object RegExp]' 等
  • instanceof 只对对象有效，原始值一律返回 false
  • 跨执行上下文（不同 iframe、worker、VM）的对象，其构造器不同，instanceof 可能失败；使用规范化检测方式（如 Array.isArray）
  • 对函数的检测：typeof fn === 'function' 简洁可靠
  • 自定义类实例检测：obj instanceof MyClass 可靠；若类库可能被多份加载，考虑暴露标记或使用 Symbol.hasInstance 定制归属逻辑

# 使用场景与区别

  • 使用 typeof 的场景：

    • 判断原始类型：数值、字符串、布尔、undefined、symbol、bigint
    • 判断是否函数：typeof value === 'function'
    • 快速分支处理输入（表单解析、序列化等）

  • 使用 instanceof 的场景：

    • 判断对象是否由某构造函数创建或继承其原型（自定义类实例、内置对象如 Date/RegExp）
    • 框架中进行类型分派（不同模型、错误类型等）

  • 关键区别：

    • 维度不同：typeof 检查“值的基本类型”，instanceof 检查“原型链归属”
    • 适用对象不同：typeof 对原始值与函数有效；instanceof 对对象有效
    • 可靠性差异：typeof 与运行时上下文无关；instanceof 受构造器来源影响（跨上下文）

# 组合策略示例

function isPlainObject(x) {
  if (x === null || typeof x !== 'object') return false;
  return Object.getPrototypeOf(x) === Object.prototype;
}

function kindOf(x) {
  if (x === null) return 'null';
  const t = typeof x;
  if (t !== 'object') return t; // 原始类型与 function 直接返回
  // 细分对象
  const tag = Object.prototype.toString.call(x); // '[object Array]' 等
  return tag.slice(8, -1).toLowerCase();
}
