# DataView

DataView 是 ArrayBuffer 的一种通用视图，提供按字节偏移读写不同数值类型的能力，并显式控制字节序（endianness）。与类型化数组不同，DataView 不受平台字节序影响，适合解析各种二进制协议/文件格式。

# 构造函数

  • new DataView(buffer, byteOffset = 0, byteLength = buffer.byteLength - byteOffset)
    • buffer：ArrayBuffer（或 SharedArrayBuffer）实例
    • byteOffset：起始字节偏移
    • byteLength：视图长度（字节）
const ab = new ArrayBuffer(16);
const dv = new DataView(ab);            // 全缓冲视图
const dv2 = new DataView(ab, 4, 8);     // 从第 5 字节开始，长度 8 字节

  • buffer：关联的 ArrayBuffer（只读）
  • byteOffset：视图起始偏移（只读）

# 实例方法（读取）

  • getInt8(offset) / getUint8(offset)
  • getInt16(offset, littleEndian?) / getUint16(offset, littleEndian?)
  • getInt32(offset, littleEndian?) / getUint32(offset, littleEndian?)
  • getFloat16(offset, littleEndian?)（部分环境）
  • getFloat32(offset, littleEndian?)
  • getFloat64(offset, littleEndian?)
  • getBigInt64(offset, littleEndian?)（部分环境）
  • getBigUint64(offset, littleEndian?)（部分环境）
const ab = new ArrayBuffer(8);
const dv = new DataView(ab);
// 写入原始字节以演示读取
new Uint8Array(ab).set([0x01, 0x00, 0x00, 0x00]);
// 按小端读取 32 位无符号整数 -> 1
dv.getUint32(0, true);
// 按大端读取 -> 0x01000000
dv.getUint32(0, false);

# 实例方法（写入）

  • setInt8(offset, value) / setUint8(offset, value)
  • setInt16(offset, value, littleEndian?) / setUint16(offset, value, littleEndian?)
  • setInt32(offset, value, littleEndian?) / setUint32(offset, value, littleEndian?)
  • setFloat16(offset, value, littleEndian?)（部分环境）
  • setFloat32(offset, value, littleEndian?)
  • setFloat64(offset, value, littleEndian?)
  • setBigInt64(offset, value, littleEndian?)（部分环境）
  • setBigUint64(offset, value, littleEndian?)（部分环境）
const ab = new ArrayBuffer(4);
const dv = new DataView(ab);
// 以小端写入 0x00000001
dv.setUint32(0, 1, true);
Array.from(new Uint8Array(ab)); // [1, 0, 0, 0]
// 以大端写入 0x00000002
dv.setUint32(0, 2, false);
Array.from(new Uint8Array(ab)); // [0, 0, 0, 2]

# 字节序（Endianness）

  • 多字节数值的存储顺序由字节序决定：小端（低字节在前）、大端（高字节在前）
  • DataView 的 get*/set* 方法通过 littleEndian 参数显式指定读写字节序，避免平台差异
// 读取 WAV/PNG 等文件头时通常要求特定字节序
const dv = new DataView(await (await fetch('/file.bin')).arrayBuffer());
const magic = dv.getUint32(0, false);   // 按文件规范选择大小端

# 64 位整数的跨浏览器处理

  • 某些环境不支持 getBigInt64/setBigInt64 与 getBigUint64/setBigUint64
  • 若仅需要安全整数范围（<= Number.MAX_SAFE_INTEGER），可用自定义读取函数
function getUint64AsNumber(dv, offset, littleEndian = true) {
  const hi = dv.getUint32(offset + (littleEndian ? 4 : 0), littleEndian);
  const lo = dv.getUint32(offset + (littleEndian ? 0 : 4), littleEndian);
  return hi * 2 ** 32 + lo; // 精度在 MAX_SAFE_INTEGER 范围内可靠
}

function setUint64FromNumber(dv, offset, value, littleEndian = true) {
  const hi = Math.floor(value / 2 ** 32);
  const lo = value >>> 0;
  if (littleEndian) {
    dv.setUint32(offset, lo, true);
    dv.setUint32(offset + 4, hi, true);
  } else {
    dv.setUint32(offset, hi, false);
    dv.setUint32(offset + 4, lo, false);
  }
}

// 需要完整 64 位范围时，优先使用 BigInt
dv.setBigUint64?.(0, 12345678901234567890n, true);

# 与 ArrayBuffer 的联系与转换

  • DataView 依附于 ArrayBuffer，通过 new DataView(buffer) 创建
  • 可与类型化数组视图混用：类型化数组适合批量/顺序读写；DataView 适合结构化解析、跨字节序读写
const ab = new ArrayBuffer(12);
const dv = new DataView(ab);
const u8 = new Uint8Array(ab);
// 先用类型化数组批量赋值，再用 DataView 按结构读写
u8.set([0x00, 0x01, 0x02, 0x03]);
dv.getUint16(2, true); // 0x0302

# 常用文件操作代码

  • 读取本地文件并解析二进制头
// <input type="file" id="pick" />
const pick = document.getElementById('pick');
pick.addEventListener('change', async (e) => {
  const file = e.target.files[0];
  const ab = await file.arrayBuffer();
  const dv = new DataView(ab);
  // 以 PNG 为例：前 8 字节魔数 0x89504E470D0A1A0A（大端比较）
  const sigHi = dv.getUint32(0, false);
  const sigLo = dv.getUint32(4, false);
  const isPNG = sigHi === 0x89504E47 && sigLo === 0x0D0A1A0A;
  // 读取首个 chunk 长度（4 字节，大端）
  const chunkLen = dv.getUint32(8, false);
});

  • 将结构化数据写入并保存为文件
function writeHeaderAndDownload() {
  const ab = new ArrayBuffer(12);
  const dv = new DataView(ab);
  dv.setUint16(0, 0x1234, true);  // 小端字段 A
  dv.setUint32(2, 0xDEADBEEF, false); // 大端字段 B
  dv.setFloat64(4, Math.PI, true); // 小端浮点 C
  const blob = new Blob([ab], { type: 'application/octet-stream' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = 'header.bin';
  a.click();
  URL.revokeObjectURL(url);
}

# 注意事项

  • 越界与对齐：读写偏移必须在 byteLength 范围内，否则抛 RangeError；某些格式字段可能要求按 2/4/8 字节对齐
  • 字节序正确性：按文件/协议规范选择大小端；误用会导致数值错误
  • 性能：频繁逐字段读写可能比类型化数组慢；批量操作优先类型化数组，结构化解析用 DataView
  • 64 位与兼容性：部分环境缺乏 BigInt64/BigUint64 支持；在不需要完整 64 位时用 Number 组合高/低 32 位，在需要时使用 BigInt
  • 与可调整大小的 ArrayBuffer：若底层缓冲区发生 resize/transfer，旧的 DataView 长度与偏移固定不变；分离（detached）后访问会抛 TypeError
