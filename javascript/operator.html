# 运算符

# 分组：()

  • 语法：(表达式)
  • 描述：提升可读性并明确评估顺序，优先级最高。
  • 示例：
3 + 4 * 5;      // 23
(3 + 4) * 5;    // 35
1
2
  • 注意事项：优先使用括号明确意图，减少依赖隐含优先级。

# 成员访问/调用/可选链/new（带参数）

  • 语法：obj.prop、obj[expr]、obj?.prop、fn(args)、new Ctor(args)
  • 描述：对象成员读写、函数调用与构造调用；可选链在访问失败时返回 undefined 而非抛错。
  • 示例：
user.profile.name;
user?.profile?.name;
get('id');
new URL('https://example.com');
1
2
3
4
  • 注意事项：
    • 可选链不可用于赋值左值；链式短路返回 undefined。
    • new 带参数与成员访问/调用同组，高优先级。

# new（无参数）

  • 语法：new Ctor
  • 描述：无参构造形式的 new，其结合性为右到左。
  • 示例：
// 右结合：new new Ctor() 等价于 new (new Ctor())
1
  • 注意事项：与成员访问/调用的绑定不同，复杂表达式中建议使用括号明确范围。

# 自增/自减（后缀、前缀）

  • 语法：x++ x-- ++x --x
  • 描述：数值加一/减一；后缀返回旧值，前缀返回新值。
  • 示例：
let x = 1;
x++ + ++x; // 1 + 3 = 4
1
2
  • 注意事项：避免在同一表达式中混用多次，降低副作用困扰。

# 一元运算

  • 语法：+x -x !x ~x typeof x void x delete obj.prop await expr
  • 描述：数值符号、布尔非、按位取反、类型查询、丢弃值、删除属性、等待 Promise。
  • 示例：
true;           // 1
!0;              // true
~5;              // -6
typeof null;     // 'object'
void 0;          // undefined
delete obj.key;  // 返回布尔值
await Promise.resolve(1);
1
2
3
4
5
6
7
  • 注意事项：
    • typeof null === 'object' 是历史遗留；判断空值用 x === null。
    • delete 仅删除对象属性，不会删除局部变量或函数参数；严格模式下删除不可配置属性会抛错。
    • await 只能在 async 函数或顶层（支持顶层 await 的环境）使用。

# 指数：**

  • 语法：a ** b
  • 描述：幂运算，右结合。
  • 示例：
2 ** 3 ** 2; // 2 ** (3 ** 2) = 512
1
  • 注意事项：
    • 与一元负号结合需加括号：-(2 ** 2)；-2 ** 2 为语法错误。

# 乘/除/取余：* / %

  • 语法：a * b a / b a % b
  • 描述：算术运算。
  • 示例：
7 % 4; // 3
1
  • 注意事项：除零返回 Infinity 或 -Infinity；0/0 为 NaN。

# 加/减：+ -

  • 语法：数值加减与字符串拼接（当任一操作数为字符串时）。
  • 示例：
1 + '2';    // '12'
'2' - 1;    // 1（减法不进行拼接）
1
2
  • 注意事项：隐式类型转换可能导致意外；必要时显式转换。

# 位移：<< >> >>>

  • 描述：对 32 位有符号/无符号整数执行位移。
  • 示例：
1 << 3;   // 8
-1 >>> 31; // 1
1
2
  • 注意事项：大数与非整数会被转换为 32 位整数；谨慎与 BigInt 混用（需使用 << 的 BigInt 重载）。

# 关系：< <= > >= in instanceof

  • 描述：大小比较、属性存在性与原型链归属。
  • 示例：
'a' < 'b';
'key' in { key: 1 };
[] instanceof Array; // true
1
2
3
  • 注意事项：
    • 字符串比较按 Unicode 码位；注意本地化排序差异。
    • in 检查对象及其原型链上属性是否存在。
    • 跨上下文的 instanceof 可能失败，使用 Array.isArray 等更稳妥方法。

# 相等：== != === !==

  • 描述：严格相等比较优先使用 ===/!==；宽松比较会进行复杂的类型转换。
  • 示例：
0 == false;      // true
0 === false;     // false
NaN === NaN;     // false（请用 Number.isNaN）
1
2
3
  • 注意事项：避免 == 带来的转换陷阱；比较 NaN 使用 Number.isNaN。

# 位与/位异或/位或：& ^ |

  • 描述：按位运算，作用于 32 位整数。
  • 示例：
5 & 3; // 1
5 ^ 3; // 6
5 | 3; // 7
1
2
3
  • 注意事项：可能触发整数化与溢出；处理标志位时较为常见。

# 逻辑与：&& 与 空值合并：??

  • 描述：短路求值；&& 在左操作数为假值时返回左值，否则返回右值；?? 在左操作数为 null/undefined 时返回右值，否则返回左值。
  • 示例：
0 && 'x';        // 0
null ?? 'x';     // 'x'
'' ?? 'x';       // ''（不是 null/undefined）
1
2
3
  • 注意事项：
    • ?? 不可与 ||/&& 混用而不加括号。
    • 合理利用短路避免不必要的计算或访问。

# 逻辑或：||

  • 描述：左操作数为假值时返回右值，否则返回左值。
  • 示例：
'' || 'fallback'; // 'fallback'
1
  • 注意事项：与 ?? 区分：|| 将 '' 0 false 视为假值，而 ?? 只区分 null/undefined。

# 条件（三元）：cond ? a : b

  • 描述：根据条件选择分支表达式。
  • 示例：
const tag = score > 90 ? 'A' : 'B';
1
  • 注意事项：避免嵌套过深；超过一层时优先使用显式 if。

# 赋值与短路赋值

  • 语法：= 及其复合赋值：+= -= *= /= %= **= <<= >>= >>>= &= |= ^=；逻辑赋值：&&= ||= ??=
  • 描述：为左值赋新值；逻辑赋值基于短路规则决定是否进行赋值。
  • 示例：
x += 2;
obj.count ??= 0;     // 若为 null/undefined 则赋值 0
flag &&= compute();  // 若 flag 为真值才赋值计算结果
1
2
3
  • 注意事项：
    • 逻辑赋值遵循短路，不触发右侧求值。
    • 为不可写或只读属性赋值会抛错（严格模式）。

# 逗号：,

  • 描述：按序求值并返回最后一个表达式的值。
  • 示例：
let a, b;
(a = 1, b = 2, a + b); // 3
1
2
  • 注意事项：降低可读性，除非在极少数场景（如 for 的头部）不建议使用。

# 其他语法提示

  • 展开/剩余 ... 并非传统运算符，但在字面量与调用上下文具有紧绑定行为；与优先级较高的成员访问/调用同层使用时通常无需担心绑定问题。
  • yield 在生成器函数内作为表达式使用，结合性类似赋值/条件的低优先级；顶层需在 function* 中使用。
