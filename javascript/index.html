# JavaScript 简介

JavaScript（简称 JS）是一门轻量级、解释型、即时编译的编程语言，最初由 Netscape 的 Brendan Eich 在 1995 年仅用 10 天时间设计完成，目的是让网页“动起来”。今天，它已成为 Web 三剑客（HTML、CSS、JavaScript）中唯一能在浏览器端直接运行的通用编程语言，并凭借 Node.js 成功“出圈”，覆盖前端、后端、移动端、桌面端、物联网、AI 脚本化等几乎所有技术场景。

# 核心特点

  1. 单线程 & 事件循环
    通过异步回调、Promise、async/await 实现非阻塞 I/O，避免多线程死锁，却又能高效处理高并发。

  2. 动态弱类型
    变量无需声明类型，运行时自动推断；隐式类型转换灵活，但也带来“== vs ===”经典面试题。

  3. 原型继承
    对象可直接继承自另一对象（__proto__ / Object.create），而非传统类式继承；ES6 引入 class 语法糖，底层仍是原型链。

  4. 函数是一等公民
    函数可以像变量一样被传递、返回、嵌套，形成闭包、高阶函数、柯里化、函数式编程等强大抽象能力。

  5. 跨平台 & 宿主环境
    浏览器提供 DOM/BOM/WebAPI；Node.js 提供文件、网络、进程等系统 API；同一门语言，不同宿主，能力天壤之别。

# 现代生态

  • 包管理：npm / yarn / pnpm，超 200 万模块，全球最大开源包仓库。
  • 构建工具：webpack / Vite / Rollup / esbuild —— 打包、压缩、热更新、Tree-Shaking。
  • 框架与库：React、Vue、Svelte、Angular、Solid、Qwik…… 组件化、响应式、SSR/SSG/ISR。
  • 服务端：Express、Koa、Fastify、NestJS、Next.js、Remix、Nuxt—— 全栈同构、边缘渲染、Serverless。
  • 移动端：React Native、Ionic、Capacitor —— 一套代码跑 iOS / Android。
  • 桌面端：Electron、Tauri —— 网页套壳成桌面软件，VS Code、Slack、飞书皆如此。
  • AI & 脚本化：TensorFlow.js、ONNX.js、Stable Diffusion WebUI 脚本层、Auto.js 自动化。
  • 嵌入式：Espruino、Low.js、JerryScript、QuickJS —— 在 64 KB 内存的单片机上跑 JS。

# 一句话总结

JavaScript 早已不是“网页小脚本”，而是连接用户界面、服务器、数据库、物联网、AI 的通用胶水语言；掌握它，你就拥有了“一次学习，多端作案”的数字通行证。
