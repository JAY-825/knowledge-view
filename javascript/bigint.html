# BigInt

BigInt 表示任意精度的整数，解决 Number 在 ±(2^53 - 1) 范围之外精度丢失的问题。适用于高精度计数、ID、加密相关整数计算等场景。

# 描述

  • 类型：原始类型（primitive），typeof 1n === 'bigint'
  • 范围：不受 53 位安全整数限制，可表示极大或极小的整数
  • 不可与 Number 混合运算；混合将抛出 TypeError
  • 支持算术、比较与部分位运算；不支持 Math.*

# 构造函数与字面量

  • 字面量：在整数末尾添加 n
const a = 123n;
const b = 9007199254740993n; // 超过 Number.MAX_SAFE_INTEGER

2
  • 构造器函数：BigInt(value)（不可使用 new）
BigInt('42');    // 42n
BigInt(42);      // 42n
// BigInt(1.5)   // RangeError（非整数）
1
2
3

# 静态方法

  • BigInt.asIntN(width, bigint)：按 width 位截断为二进制补码，返回有符号范围的值
  • BigInt.asUintN(width, bigint)：按 width 位截断，返回无符号范围的值
BigInt.asIntN(64, 2n ** 63n);    // -9223372036854775808n
BigInt.asUintN(64, -1n);         // 18446744073709551615n
1
2

# 实例方法

  • toString(radix = 10)：以指定进制返回字符串
  • toLocaleString(locales?, options?)：本地化格式化为字符串
  • valueOf()：返回其原始值（通常无需直接调用）
(255n).toString(16);          // 'ff'
(1000000000000000000n).toLocaleString('zh-CN');

# 运算与比较

  • 算术：+ - * / % **
  • 比较：< <= > >= === !==
  • 位运算：& | ^ ~ << >>（不支持 >>>）
10n + 5n;          // 15n
10n / 3n;          // 3n（整数除法，向零截断）
2n ** 63n;         
5n & 3n;           // 1n
1n << 3n;          // 8n
10n > 9n;          // true

# 与 Number 的互操作

  • 显式转换：Number(bigint) 或 BigInt(number)
  • 注意：将超出安全范围的 BigInt 转为 Number 会损失精度
Number(9007199254740993n);          // 9007199254740992（精度丢失）
BigInt(42);                         // 42n
1
2

# 注意事项

  • 不可使用 new：new BigInt(1) 会抛出错误，应使用 BigInt(1) 或字面量 1n
  • 不与 Number 混合运算：
1n + 1;      // TypeError
2n * 3;      // TypeError
1
2
  • 一元 + 不支持：
+1n;         // TypeError（为兼容 asm.js，BigInt 禁止一元 +）
1
  • 除法向零取整：
5n / 2n;     // 2n（不会产生小数部分）
1
  • 位运算不支持 >>>：
// 仅支持：& | ^ ~ << >> （不支持 >>>）
1
  • 不可用于 Math.*：
Math.max(1n, 2n);  // TypeError
1
  • 严格相等与宽松相等：
1n === 1;   // false
1n == 1;    // true
1
2
  • 布尔转换与条件：
Boolean(0n); // false
Boolean(1n); // true
if (1n) { /* 进入分支 */ }

  • JSON 序列化：JSON.stringify(1n) 抛 TypeError，需转字符串或自定义 toJSON
  • 密码学场景：BigInt 操作非常数时间，不适合加密算法实现

# 序列化与存储

  • JSON.stringify 不支持 BigInt，会抛出 TypeError
  • 方案：转换为字符串或十进制文本；或使用自定义序列化/反序列化
const obj = { id: 12345678901234567890n };
JSON.stringify({ id: obj.id.toString() });

  • BigInt64Array 与 BigUint64Array 支持 64 位整型数组

a[0] = 1n;

# 使用建议

  • 在需要超过 Number.MAX_SAFE_INTEGER 范围的整数场景使用 BigInt
  • 不与 Number 混算；必要时在边界转换并标注语义（如 ID 始终为字符串或 BigInt）
  • 避免依赖 Math；若需数学函数，选择适配 BigInt 的算法实现
  • 序列化时明确策略：字符串化或十进制文本；数据库层面选择支持大整数的类型
  • 跨 API/网络边界传递时统一规范（字符串或十进制文本），避免隐式精度损失
