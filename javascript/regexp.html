# 正则表达式

正则表达式用于对字符串执行复杂的匹配、搜索与替换。掌握转义规则、JS 支持正则的 API 以及常见校验场景，可以高效解决文本处理问题。

# 转义符与字符类

转义序列的含义如下（以 JS 正则为准）：

符号 含义 示例
\d 数字字符 [0-9] /\d+/ 匹配一个或多个数字
\D 非数字字符 /\D+/
\w 字母、数字、下划线 [A-Za-z0-9_] /\w+/
\W 非 \w /\W+/
\s 空白字符（空格、制表、换行等） /\s+/
\S 非空白字符 /\S+/
\b 单词边界 /\bword\b/
\B 非单词边界 /\Bword\B/
\t 制表符 /\t/
\n 换行 /\n/
\r 回车 /\r/
\f 换页 /\f/
\v 垂直制表 /\v/
\0 NUL 字符 /\0/
\xhh 两位十六进制的字符 /\x41/ → A
\uhhhh 四位十六进制的 Unicode /\u4E2D/ → 中
\u{...} 码点形式（需 u 标志） /\u{1F600}/u → 😀
\. 句点的字面量 /\./
\* \+ \? 量词的字面量 /a\+/ 匹配 a+
\| \( \) \[ \] \{ \} 元字符的字面量 /\[abc\]/ 匹配字面量方括号
\^ \$ 行首、行尾字面量 /\^\$/

提示：在“JS 字符串字面量”中书写正则时，反斜杠需要二次转义，例如：new RegExp("\\d+") 等价于 /\d+/。

常用量词与分组：

  • * 0 次或多次，+ 1 次或多次，? 0 次或 1 次，{m,n} 区间次数
  • 分组：(...)，非捕获分组：(?:...)
  • 前后查看：正向肯定 (?=...)，正向否定 (?!...)，反向肯定 (?<=...)，反向否定 (?<!...)

常用标志（flags）：

  • g 全局匹配；i 忽略大小写；m 多行（^/$ 匹配行首/行尾）；
  • s 使 . 匹配换行；u Unicode 模式；y 粘连匹配。

# 支持正则的常用 API

  • RegExp.prototype.test(string)：返回布尔值
  • RegExp.prototype.exec(string)：返回匹配信息或 null
  • String.prototype.match(regexp)：返回匹配数组或 null（不含捕获组详细信息）
  • String.prototype.matchAll(regexp)：返回可迭代器，需 g 标志，包含捕获组
  • String.prototype.search(regexp)：返回首个匹配的索引或 -1
  • String.prototype.replace(regexp, replacement|fn)：替换匹配内容
  • String.prototype.replaceAll(regexp|string, replacement)：替换所有匹配（正则需 g）
  • String.prototype.split(regexp|string, limit?)：按正则拆分字符串
  • new RegExp(pattern, flags?)：动态创建正则

# 注意事项

  • 正则字面量与 RegExp 构造器的转义差异：在字符串中需要双反斜杠。
  • 使用 u 标志处理 Unicode 字符与码点；避免把代理对拆错。
  • 复杂校验（如身份证日期合法性、校验位算法）建议结合程序逻辑而非仅靠正则完成。
  • 谨慎使用回溯密集的模式，避免性能问题；优先使用明确的分组与锚点。
