# Symbol

Symbol 是一种原始数据类型，表示独一无二的标识符。可用作对象的私有属性键，避免与字符串键发生冲突；还包含一组内置的“通用（well-known）symbol”用于定制语言内部行为。

# 构造函数

  • Symbol(description?)：创建一个唯一的 symbol 值（不可使用 new）
  • Object(sym)：创建 symbol 的包装对象（一般不需要）
const s1 = Symbol('id');
const s2 = Symbol('id');
s1 === s2;                   // false（每次调用均唯一）

typeof s1;                   // 'symbol'
Object(s1) instanceof Object; // true（包装对象）

# 静态属性

  • Symbol.length：长度为 0
  • Symbol.prototype：原型对象
  • 内置通用 symbol（部分常用列举）：
    • Symbol.iterator、Symbol.asyncIterator
    • Symbol.match、Symbol.replace、Symbol.search、Symbol.split
    • Symbol.hasInstance、Symbol.isConcatSpreadable、Symbol.unscopables
    • Symbol.species、Symbol.toPrimitive、Symbol.toStringTag

示例：迭代、拼接展平、toStringTag

// 自定义迭代
const range = {
  start: 1, end: 3,
  [Symbol.iterator]() {
    let i = this.start;
    return { next: () => ({ value: i, done: i++ > this.end }) };
  }
};
[...range]; // [1, 2, 3]

// 控制 concat 展平
const arrLike = { 0: 'a', 1: 'b', length: 2, [Symbol.isConcatSpreadable]: true };
[1, 2].concat(arrLike); // [1, 2, 'a', 'b']

// 自定义 toStringTag
class Person { get [Symbol.toStringTag]() { return 'Person'; } }
Object.prototype.toString.call(new Person()); // '[object Person]'

# 静态方法

  • Symbol.for(key)：从全局注册表获取/创建共享 symbol
  • Symbol.keyFor(sym)：从全局注册表取回共享 symbol 的 key
const a = Symbol.for('token');
const b = Symbol.for('token');
a === b; // true（共享）
Symbol.keyFor(a); // 'token'

Symbol.keyFor(Symbol('x')); // undefined（非共享）

# 实例属性

  • Symbol.prototype.description：创建时的描述字符串（只读）
Symbol('user').description; // 'user'

# 实例方法

  • toString()：返回 'Symbol(...)' 字符串
  • valueOf()：返回自身
const s = Symbol('x');
String(s);     // 'Symbol(x)'
s.toString();  // 'Symbol(x)'
s.valueOf() === s; // true

# 注意事项

  • 不可使用 new：new Symbol() 抛 TypeError
  • 与数值运算/转换：+s、Number(s) 抛 TypeError
  • 字符串拼接：'id:' + s 抛 TypeError；使用 String(s) 或 s.toString()
  • 枚举性：symbol 键不会出现在 for...in、Object.keys 中；使用 Object.getOwnPropertySymbols 或 Reflect.ownKeys
  • JSON：JSON.stringify 会忽略 symbol 键，symbol 值会被忽略（结果为 {} 或 undefined）
const key = Symbol('secret');
const obj = { [key]: 123, normal: 1 };
Object.keys(obj);               // ['normal']
Object.getOwnPropertySymbols(obj); // [key]
Reflect.ownKeys(obj);           // ['normal', key]
JSON.stringify(obj);            // '{"normal":1}'
JSON.stringify(key);            // undefined

# 常用功能示例

  • 私有属性键与避免冲突
const ID = Symbol('ID');
const user = { name: 'Alice', [ID]: 1001 };
user[ID]; // 1001
for (const k in user) { /* 不会枚举到 ID */ }

  • instanceof 定制（静态）
class Even {
  static [Symbol.hasInstance](x) { return typeof x === 'number' && x % 2 === 0; }
}
4 instanceof Even;  // true
5 instanceof Even;  // false

  • 正则行为定制（match/replace）
class StartsWith {
  constructor(prefix) { this.prefix = prefix; }
  [Symbol.match](str) { return str.startsWith(this.prefix) ? [this.prefix] : null; }
}
'hello'.match(new StartsWith('he')); // ['he']

  • species 定制派生类型
class MyArray extends Array {
  static get [Symbol.species]() { return Array; }

const a = new MyArray(1, 2, 3);
a.map(x => x * 2) instanceof Array;   // true（派生为 Array）

const asyncRange = {
  start: 1, end: 3,
  async *[Symbol.asyncIterator]() {

  }
