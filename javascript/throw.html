# throw语句

throw 用于在执行过程中主动抛出异常，立即中断当前执行并将控制权转交给最近的 try...catch；若未被捕获，则会导致程序（当前任务）异常终止或在异步上下文中导致 Promise 拒绝。

# 语法

throw 表达式
1
  • 表达式 可以是任意值（对象、字符串、数字、布尔值等），惯用做法是抛出 Error 实例或其子类。
  • 一旦执行到 throw，当前函数后续语句不会执行；控制流跳转到可捕获该异常的最近 catch。

# 描述

  • 典型错误类型：Error、TypeError、RangeError、ReferenceError、SyntaxError、URIError 等。
  • 同步代码中，未被捕获的异常会使当前调用栈展开直至顶层；异步（例如 async 函数或 Promise 执行器）中 throw 会转换为 Promise 的拒绝态。
  • 自定义错误可通过继承 Error 来携带更明确的错误类型与语义。

# 示例

输入校验

function divide(a, b) {
  if (typeof a !== 'number' || typeof b !== 'number') {
    throw new TypeError('divide expects number arguments');
  }
  if (b === 0) throw new RangeError('division by zero');
  return a / b;
}

try {
  divide(6, 0);
} catch (e) {
  console.error(e.name, e.message);
}

function parseJSONSafe(text) {
  try {
    return JSON.parse(text);
  } catch (err) {
    // 记录后再抛出，交由上层统一处理
    console.warn('parse failed:', err.message);
    throw err;
  }
}

自定义错误类型

class ValidationError extends Error {
  constructor(message, code) {
    super(message);
    this.name = 'ValidationError';
    this.code = code;
  }
}

function requireNonEmpty(str) {
  if (typeof str !== 'string' || str.trim() === '') {
    throw new ValidationError('string required', 'EMPTY');
  }
  return str;
}

# 使用注意事项

  • 优先抛出 Error 及其子类，避免抛出原始字符串或数字，提升可读性与可调试性。
  • 错误信息应清晰可定位：包含期望、实际值或关键上下文。
  • 在派生类中正确调用 super(message)，并设置 name 字段以区分错误类型。
  • 尽量在边界处早抛出（输入校验、状态检查），在统一的上层捕获并记录。
  • finally 中不要无条件 throw 或返回，避免吞掉原始错误；如需清理请谨慎处理返回值与抛出逻辑。
  • 在 async/Promise 链中，throw 等价于返回一个被拒绝的 Promise；在消费端使用 .catch 或 try...catch（配合 await）处理。
  • 面向库开发时暴露稳定的错误类型/代码，方便调用方进行分类处理。
