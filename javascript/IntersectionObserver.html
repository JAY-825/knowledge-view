# IntersectionObserver（元素可见性观察器）

IntersectionObserver 是浏览器提供的 Web API，用于高效地观察目标元素与某个“根容器”（root）的交叉状态（是否进入可视区域、可见比例等）。它常用于懒加载、曝光统计、无限滚动、虚拟列表辅助、滚动联动等场景，用来替代手写 scroll + getBoundingClientRect 的高频计算。

# 一、能解决什么问题

# 1. 常见应用场景

  1. 图片/视频懒加载：元素进入视口再加载资源
  2. 无限滚动：底部哨兵元素进入视口触发下一页加载
  3. 曝光/埋点：元素达到一定可见比例时上报一次
  4. 滚动联动：高亮目录、吸顶效果触发点判断
  5. 预加载：元素将进入视口时提前请求数据或资源（配合 rootMargin）

# 2. 相对 scroll 事件的优势

  • 回调是异步批量触发，不必在每次滚动时同步计算全部元素
  • 由浏览器统一调度与合并计算，通常更省资源
  • 支持 root 容器（可监听某个滚动容器内部的可见性）

# 二、基础概念

# 1. root（根容器）

  • 默认 root 为浏览器视口（viewport），即 null
  • 也可以指定某个可滚动容器元素作为 root，用于观察该容器内部的可见性

# 2. rootMargin（根容器扩展边距）

rootMargin 类似 CSS margin 的写法，用于扩展/收缩 root 的判定区域（对“触发时机”很关键），常用于预加载。

{
  root: null,
  rootMargin: '200px 0px 200px 0px'
}

# 3. threshold（阈值）

threshold 表示可见比例（intersectionRatio）达到这些值时触发回调：

  • 0：刚进入/刚离开（最常用）
  • 0.5：可见一半
  • [0, 0.25, 0.5, 0.75, 1]：分段触发

# 三、基本用法

IntersectionObserver 使用步骤通常是：

  1. new IntersectionObserver(callback, options)
  2. observer.observe(target)
  3. 需要时 observer.unobserve(target) 或 observer.disconnect()

# 1. 最小示例：进入视口打印日志

<div style="height: 120vh; background: #eee;">scroll down</div>
<div id="target" style="height: 120px; background: #cde;">target</div>
<script>
  const target = document.querySelector('#target');

  const observer = new IntersectionObserver((entries) => {
    for (const entry of entries) {
      console.log('isIntersecting:', entry.isIntersecting);
      console.log('ratio:', entry.intersectionRatio);
    }
  });

  observer.observe(target);
</script>

# 五、IntersectionObserverEntry 字段说明

回调参数 entries 是 IntersectionObserverEntry 数组，常用字段如下：

  • target：被观察的目标元素
  • isIntersecting：是否与 root 发生交叉（常用于“进入/离开”）
  • intersectionRatio：交叉区域占目标面积的比例（0 ~ 1）
  • intersectionRect：交叉区域矩形
  • boundingClientRect：目标元素的矩形信息（相对视口）
  • rootBounds：根容器矩形信息（root 为 null 时是视口）
  • time：该记录产生的时间戳（高精度，便于调试）

# 七、实用案例

# 1. 图片懒加载（进入可视区再设置 src）

<img data-src="https://example.com/a.jpg" width="320" height="180" />
<img data-src="https://example.com/b.jpg" width="320" height="180" />
<script>
  const images = document.querySelectorAll('img[data-src]');

  const io = new IntersectionObserver((entries, obs) => {
    for (const entry of entries) {
      if (!entry.isIntersecting) continue;
      const img = entry.target;
      const src = img.getAttribute('data-src');
      if (src) {
        img.src = src;
        img.removeAttribute('data-src');
      }
      obs.unobserve(img);
    }
  }, {
    root: null,
    rootMargin: '200px 0px',
    threshold: 0
  });

  images.forEach(img => io.observe(img));
</script>

# 2. 无限滚动（底部哨兵触发加载）

<ul id="list"></ul>
<div id="sentinel" style="height: 1px;"></div>
<script>
  const list = document.querySelector('#list');
  const sentinel = document.querySelector('#sentinel');

  let page = 0;
  let loading = false;
  let done = false;

  function renderItems(items) {
    const frag = document.createDocumentFragment();
    for (const text of items) {
      const li = document.createElement('li');
      li.textContent = text;
      frag.appendChild(li);
    }
    list.appendChild(frag);
  }

  async function loadNext() {
    if (loading || done) return;
    loading = true;
    page += 1;
    const items = Array.from({ length: 20 }, (_, i) => `page-${page} item-${i}`);
    await new Promise(r => setTimeout(r, 300));
    renderItems(items);
    if (page >= 5) done = true;
    loading = false;
  }

  const io = new IntersectionObserver((entries) => {
    const entry = entries[0];
    if (!entry?.isIntersecting) return;
    loadNext();
  }, {
    root: null,
    rootMargin: '200px 0px',
    threshold: 0
  });

  io.observe(sentinel);
  loadNext();
</script>

# 3. 曝光统计（达到 50% 可见比例上报一次）

const cards = document.querySelectorAll('.card');
const reported = new WeakSet();

const io = new IntersectionObserver((entries) => {
  for (const e of entries) {
    if (e.intersectionRatio < 0.5) continue;
    if (reported.has(e.target)) continue;
    reported.add(e.target);
    const id = e.target.getAttribute('data-id');
    console.log('report impression:', id);
  }
}, { threshold: [0.5] });

cards.forEach(el => io.observe(el));

# 4. 目录高亮（文章阅读位置联动）

思路：观察每个 heading，当它接近视口顶部时认为“当前章节”。

const headings = Array.from(document.querySelectorAll('article h2, article h3'));
const tocLinks = new Map(headings.map(h => [h.id, document.querySelector(`a[href="#${h.id}"]`)]));

function setActive(id) {
  for (const [key, link] of tocLinks) {
    if (!link) continue;
    link.classList.toggle('active', key === id);
  }
}

const io = new IntersectionObserver((entries) => {
  const visible = entries
    .filter(e => e.isIntersecting)
    .sort((a, b) => a.boundingClientRect.top - b.boundingClientRect.top);
  const top = visible[0]?.target;
  if (top?.id) setActive(top.id);
}, {
  root: null,
  rootMargin: '-20% 0px -70% 0px',
  threshold: 0
});

headings.forEach(h => h.id && io.observe(h));

# 八、最佳实践与注意事项

  1. 及时 unobserve/disconnect：一次性任务（如懒加载、曝光一次）完成后解除观察
  2. 用 rootMargin 做预加载：不要等到完全进入视口才加载，避免白屏/闪烁
  3. threshold 数组不宜过密：阈值越多触发越频繁，按业务选择必要粒度
  4. 回调内避免重计算：entries 可能批量到达，处理尽量轻量，必要时合并到 requestAnimationFrame
  5. 注意容器滚动：root 不是视口时，要确认目标在 root 的可视区域内滚动

# 九、常见问题

# 1. 为什么元素已经在视口里但没触发

可能原因：

  1. target 尚未 observe
  2. root 设置不正确（root 不是视口且不是目标的合适祖先）
  3. threshold 设置过高（例如阈值为 1 需要完全可见）
  4. 目标元素 display: none 或尺寸为 0

# 2. IntersectionObserver 能监听“元素是否被遮挡”吗

不能精确判断“是否被其它元素遮挡”。它判断的是 target 与 root 的几何交叉，不关心覆盖层遮挡。

# 3. 如何兼容不支持的浏览器

思路：

  1. 通过特性检测：'IntersectionObserver' in window
  2. 不支持时降级为 scroll + getBoundingClientRect（建议做节流/防抖）
