# JSDoc 注释规范与用法

JSDoc 是 JavaScript 的文档注释规范，能够描述函数、类、模块、类型与接口等信息。它可以被编辑器、类型检查器与文档生成工具识别，从而提升代码可读性与维护性。

# 九、与 TypeScript 协作建议

  1. 在 JS 项目中开启 checkJs 与 allowJs，可让编辑器基于 JSDoc 推导类型
  2. 复杂类型建议先用 @typedef 抽离，再在函数中复用
  3. JSDoc 与 TS 类型表达不同，尽量保持一套注释风格

# 十、编写注意事项

  1. 注释与实现保持同步，避免过期信息
  2. 参数顺序要与函数定义一致
  3. 对象参数建议拆解属性说明
  4. 公共 API 优先补充示例与异常说明
