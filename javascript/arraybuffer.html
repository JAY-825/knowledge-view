# ArrayBuffer

ArrayBuffer 表示一段原始二进制内存缓冲区，本身不提供读写方法，需要通过类型化数组（如 Uint8Array、Int32Array）或 DataView 进行访问。它支持可调整大小（resizable）、可传输（transferable），常用于网络、文件、图像、音视频等二进制数据处理。

# 构造函数

  • new ArrayBuffer(byteLength, options?)
    • byteLength：初始字节长度
    • options.maxByteLength：可选，若提供则缓冲区可调整大小（resizable: true），最大字节长度为该值
// 固定长度 8 字节
const buf = new ArrayBuffer(8);
console.log(buf.byteLength); // 8

// 可调整大小：初始 8 字节，最大 32 字节
const resizable = new ArrayBuffer(8, { maxByteLength: 32 });
console.log(resizable.resizable, resizable.maxByteLength); // true 32

// 通过视图读写
const view = new Int32Array(resizable); // 每元素 4 字节
view[0] = 123;

// 扩容（新增字节会被置为 0）
resizable.resize(16);
console.log(resizable.byteLength); // 16
console.log(view.length); // 仍是 2（老视图长度不变）；新长度需重建视图
const view2 = new Int32Array(resizable);
console.log(view2.length); // 4

# 静态方法

  • ArrayBuffer.isView(arg)：判断参数是否为 ArrayBuffer 的视图（类型化数组或 DataView）
const buf = new ArrayBuffer(4);
ArrayBuffer.isView(new Uint8Array(buf)); // true
ArrayBuffer.isView(new DataView(buf));   // true
ArrayBuffer.isView(buf);                  // false

# 实例属性

  • byteLength：当前字节长度（分离后为 0）
  • resizable：是否可调整大小
  • maxByteLength：最大字节长度（仅在可调整大小时有意义）
  • detached：是否已分离（被传输后原缓冲区会分离）
  • constructor、[Symbol.toStringTag]
const ab = new ArrayBuffer(8, { maxByteLength: 16 });
ab.resizable;     // true
ab.maxByteLength; // 16

# 实例方法

  • resize(newByteLength)：调整字节长度（仅 resizable 为 true 的情况下可用）
  • slice(begin, end?)：复制一个新缓冲区
  • transfer()：创建一个拥有相同内容的新缓冲区，并分离当前缓冲区
  • transferToFixedLength()：创建一个不可调整大小的新缓冲区，并分离当前缓冲区
const ab = new ArrayBuffer(8, { maxByteLength: 16 });
const u8 = new Uint8Array(ab);
u8.set([1, 2, 3, 4]);

// 切片复制
const copy = ab.slice(0, 4);
new Uint8Array(copy); // [1, 2, 3, 4]

// 传输：原 ab 将被分离（不可再用）
const moved = ab.transfer();
console.log(ab.byteLength); // 0
try { ab.resize(16); } catch (e) { /* TypeError */ }

// 固定长度传输
const fixed = moved.transferToFixedLength();

# 注意事项

  • 分离（detached）：缓冲区被传输后原对象分离，byteLength 变为 0，操作方法抛 TypeError；关联的视图对象也会抛错
  • 仅一个拥有者：任意时刻只有一个副本拥有底层内存；跨线程或上下文传输请使用 postMessage 的可转移对象机制或 transfer/transferToFixedLength
  • 调整大小：扩容新增字节初始化为 0；收缩可能截断数据；老视图不会随长度自动变化，需重建新视图
  • 与 SharedArrayBuffer 区别：SharedArrayBuffer 用于多线程共享内存，不支持调整大小与传输；ArrayBuffer 支持传输与可调整大小（若构造时提供 maxByteLength）
  • 性能建议：避免频繁复制大缓冲区；优先使用视图在现有缓冲上操作；跨线程传输优先使用可转移对象防止拷贝

  • 保存为文件（浏览器下载）
function downloadArrayBuffer(ab, filename, type = 'application/octet-stream') {
  const blob = new Blob([ab], { type });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = filename;
  a.click();
  URL.revokeObjectURL(url);
}

  • 分片上传（示例）
async function uploadInChunks(file, chunkSize = 1024 * 1024) {
  const total = Math.ceil(file.size / chunkSize);
  for (let i = 0; i < total; i++) {
    const start = i * chunkSize;
    const end = Math.min(start + chunkSize, file.size);
    const chunk = file.slice(start, end);
    const ab = await chunk.arrayBuffer();
    await fetch('/upload', { method: 'POST', body: ab });
  }
}

  • 计算哈希（SHA-256）
async function sha256(ab) {
  const hash = await crypto.subtle.digest('SHA-256', ab);
  return Array.from(new Uint8Array(hash)).map(b => b.toString(16).padStart(2, '0')).join('');
}

// 前 4 字节保留，新增字节为 0

// 传输所有权并检查分离状态
