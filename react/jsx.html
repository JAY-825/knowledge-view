# JSX 语法

JSX（JavaScript XML）是 JavaScript 的一种语法扩展，可以让你在 JavaScript 中编写类似 HTML 的标记。JSX 是 React 的核心组成部分，它使得编写 UI 组件更加直观和高效。

# 一、JSX 是什么

JSX 看起来像 HTML，但它实际上是 React.createElement() 的语法糖。浏览器无法直接解析 JSX，需要通过 Babel 等工具编译为标准的 JavaScript。

// JSX 写法
const element = <h1>Hello, World!</h1>;

// 编译后
const element = React.createElement("h1", null, "Hello, World!");

# 二、基础语法规则

# 1. 单个根元素

JSX 表达式必须只有一个根元素。如果需要返回多个元素，需要用 <div> 或 <></>（Fragment）包裹。

// 错误：多个根元素
const element = (
  <h1>Title</h1>
  <p>Content</p>
);

// 正确：单个根元素
const element = (
  <div>
    <h1>Title</h1>
    <p>Content</p>
  </div>
);

// 也可以用 Fragment（不会生成额外的 DOM 节点）
const element = (
  <>
    <h1>Title</h1>
    <p>Content</p>
  </>
);

# 三、嵌入 JavaScript 表达式

在 JSX 中使用花括号 {} 嵌入 JavaScript 表达式。

const name = "Alice";
const age = 25;
const user = { firstName: "Bob", lastName: "Smith" };

const element = (
  <div>
    {/* 嵌入变量 */}
    <h1>Hello, {name}</h1>

    {/* 嵌入表达式（运算、函数调用等） */}
    <p>年龄：{age + 1}</p>
    <p>{user.firstName + " " + user.lastName}</p>

    {/* 三元表达式 */}
    <p>{age >= 18 ? "成年人" : "未成年人"}</p>

    {/* 函数调用 */}
    <p>{formatName(user)}</p>
  </div>
);

# 五、列表渲染

使用 Array.map() 渲染列表，并给每个元素设置唯一的 key 属性。

function TodoList({ todos }) {
  return (
    <ul>
      {todos.map((todo) => (
        <li key={todo.id}>
          <span style={{ textDecoration: todo.done ? "line-through" : "none" }}>
            {todo.text}
          </span>
        </li>
      ))}
    </ul>
  );
}

// 也可以获取索引
function List({ items }) {
  return (
    <ul>
      {items.map((item, index) => (
        <li key={item.id || index}>
          {item.name} - 第{index + 1}项
        </li>
      ))}
    </ul>
  );
}

# 为什么要 key

React 用 key 来识别列表中哪些元素发生了变化，从而提高渲染性能。key 应当：

  • 在当前列表中唯一
  • 是稳定不变的标识（如 ID）
  • 避免使用索引作为 key（尤其是在列表会重新排序的情况下）
// 推荐：使用稳定的 ID
{
  users.map((user) => <UserCard key={user.id} user={user} />);
}

// 不推荐：使用索引（列表可能变化时会出现问题）
{
  users.map((user, index) => <UserCard key={index} user={user} />);
}

# 七、事件处理

function App() {
  const handleClick = (e) => {
    // e 是 React 的合成事件（SyntheticEvent）
    e.preventDefault();
    console.log("按钮被点击");
  };

  const handleChange = (e) => {
    console.log("输入值:", e.target.value);
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log("表单提交");
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="text" onChange={handleChange} />
      <button onClick={handleClick}>提交</button>
    </form>
  );
}

# 十二、JSX 的工作原理

JSX 会被 Babel 编译为 React.createElement() 调用，最终生成一个描述 UI 结构的 JavaScript 对象（被称为"React 元素"）。

// JSX
const element = (
  <div className="container">
    <h1>Hello</h1>
  </div>
);

// 编译后等价于：
const element = React.createElement(
  "div",
  { className: "container" },
  React.createElement("h1", null, "Hello"),
);

// 最终生成的对象结构（简化）
const element = {
  type: "div",
  props: {
    className: "container",
    children: {
      type: "h1",
      props: {
        children: "Hello",
      },
    },
  },
};

# 十三、自定义组件必须以大写字母开头

JSX 中，小写字母开头的标签被认为是原生 HTML 元素，大写字母开头的标签被认为是自定义组件。

// 小写 → 原始 DOM 元素
const element1 = <div />;

// 大写 → 自定义组件
const element2 = <MyComponent />;

// 错误示例
function myComponent() {
  return <div>内容</div>;
}
// <myComponent />  会被当成 DOM 元素渲染，不会调用你的函数

# 4. JSX 中 Vue 指令的替代写法

在 JSX 中，Vue 内置指令需要使用对应的替代方式：

Vue 模板指令 JSX / 渲染函数写法
v-model value + onInput 或 modelValue + onUpdate:modelValue
v-if 三元表达式 condition ? <A /> : <B /> 或 &&
v-for items.map(item => ...)
v-show style={ { display: show ? '' : 'none' } }
v-on onClick、onInput 等事件属性
v-bind 直接作为属性，如 title={value}
v-html innerHTML={htmlString}
v-text 直接作为文本子节点 {text}
// Vue 模板写法
// <input v-model="text" />

// JSX 写法
import { ref } from "vue";

export default defineComponent({
  setup() {
    const text = ref("");

    return () => (
      <input
        value={text.value}
        onInput={(e) => {
          text.value = e.target.value;
        }}
      />
    );
  },
});

// 默认 v-model（等价于传 modelValue + onUpdate:modelValue）
export default defineComponent({
  props: {
    modelValue: String,
  },
  emits: ['update:modelValue'],
  setup(props, { emit }) {
    return () => (

        value={props.modelValue}

// 多个 v-model
export default defineComponent({

          value={props.title}
          onInput={(e) => emit('update:title', e.target.value)}
        />
        <textarea
          value={props.content}
          onInput={(e) => emit('update:content', e.target.value)}

# 9. Vue JSX vs React JSX 主要差异

特性 React JSX Vue JSX
组件定义 函数组件 / class 组件 defineComponent 或选项式对象
数据绑定 单向：{} 单向：{}
响应式数据 useState / useReducer ref() / reactive()，访问需要 .value
样式 class className class（Vue JSX 中 class 和 className 都可用）
指令替代 无指令概念 v-if → 三元，v-for → map，v-model → value+onInput
插槽 children prop slots.default?.()
事件 onClick onClick
渲染函数 组件函数直接返回 JSX return () => (JSX)

# 总结

  • JSX 是 JavaScript 的语法扩展，让 UI 代码更直观
  • JSX 表达式需要单个根元素、标签闭合、驼峰命名属性
  • 使用 {} 嵌入 JavaScript 表达式
  • 条件渲染用三元表达式、&& 或提前 return
  • 列表渲染用 map()，配合唯一 key
  • 内联样式用 JS 对象，CSS 类名用 className（React）/ class（Vue JSX）
  • Vue 3 原生支持 JSX，通过 @vitejs/plugin-vue-jsx 插件即可使用
  • Vue JSX 中使用 slots、emit 等 API 替代模板中的指令和语法糖
