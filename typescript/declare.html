# declare关键字

declare 用于在 TypeScript 中声明“外部存在”的变量、函数、类、模块、命名空间、全局扩展等，以便进行类型检查而不生成任何运行时代码。它常见于 *.d.ts 声明文件，也可用于模块或全局的类型增补。

# 语法

  • 变量与常量：declare let/const/var 名称: 类型;
  • 函数：declare function 名称(参数: 类型): 返回类型;
  • 类：declare class 名称 { 成员: 类型; }
  • 枚举：declare enum 名称 { 成员 }
  • 命名空间：declare namespace 名称 { ... }
  • 模块声明与模块扩展：declare module '包名' { ... }
  • 全局扩展：declare global { ... }

在 *.d.ts 中顶层默认处于“声明上下文”，通常可省略 declare；在普通 *.ts 文件中进行增补时需要使用 declare。

# 描述

  • 目的：为已有的运行时代码（第三方库、全局对象、资源模块）提供类型信息；或对现有类型进行扩展（模块/全局增补）。
  • 产物：declare 声明不产生任何 JavaScript 输出，仅参与类型检查与提示。
  • 常见场景：
    • 为无类型的全局库提供声明（如 UMD 全局）
    • 为打包器资源（如 *.svg、*.png）提供模块类型
    • 扩展第三方库的模块类型（模块增补）
    • 扩展全局对象（Window、NodeJS.ProcessEnv 等）

# 使用注意事项

  • 仅类型声明：declare 不生成运行时代码，确保真实的运行时实体存在，否则将出现未定义错误。
  • 优先声明文件：将全局与模块增补放入 *.d.ts，并通过 tsconfig.json 的 include/typeRoots 管理。
  • 模块化防污染：在声明文件中使用 export {} 保持模块作用域，再进行 declare global 扩展。
  • 谨慎全局扩展：优先模块增补，其次全局扩展；避免与他人声明冲突。
  • 与 import type 配合：在仅需要类型时使用 import type，减少运行时依赖。
  • 正确区分：在 *.d.ts 顶层可省略 declare；在普通 *.ts 文件中进行外部声明时必须使用 declare。
  • 版本与兼容：扩展第三方库的类型时与其版本保持一致，否则可能导致类型不匹配。
