# 函数

函数类型描述参数、返回值以及 this 的约束。泛型与重载让函数在保持类型安全的同时具备灵活的表现力。

# 函数类型与参数

function add(a: number, b: number): number { return a + b }
const mul: (x: number, y: number) => number = (x, y) => x * y;
1
2
  • 可选参数：(x?: number)，默认值：(x = 0)，剩余参数：(...args: T[])
function sum(...xs: number[]): number { return xs.reduce((a, b) => a + b, 0) }
1

# this 参数

  • 通过显式的 this 参数约束调用方式（仅类型层面）
function move(this: { x: number }, dx: number) { this.x += dx }
1

# 函数重载

  • 为同名函数声明多组签名，提供更友好的调用体验
function get(id: number): number[];
function get(id: string): string[];
function get(id: number | string) { return [] }

# 泛型函数与约束

function identity<T>(x: T): T { return x }
function pick<T, K extends keyof T>(obj: T, key: K): T[K] { return obj[key] }
1
2

# 高阶函数与回调

type Mapper<T, R> = (value: T, index: number) => R;
function map<T, R>(list: T[], fn: Mapper<T, R>): R[] { return list.map((v, i) => fn(v, i)) }

# 注意事项

  • 避免在回调中使用广泛的 any，优先泛型与上下文类型推断
  • 重载实现体需兼容所有签名的并集
  • 对外 API 尽量使用精确的函数类型与返回值，避免 any
