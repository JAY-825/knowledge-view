# 枚举

枚举用来表示一组有限的常量集合。TypeScript 支持数字枚举、字符串枚举与常量枚举。

# 数字枚举

  • 默认从 0 开始递增，支持显式赋值与部分计算值
  • 具有反向映射（数字到名字）
enum Status { Init, Loading, Done }
const s: Status = Status.Done;
Status[0];

# 字符串枚举

  • 值为字符串字面量，无反向映射，易于序列化与日志
enum Role { Admin = 'admin', User = 'user' }
1

# 常量枚举

  • const enum 在编译阶段内联，消除对象生成与访问开销
const enum Op { Add, Sub }
const r = Op.Add;
1
2

# 位标志枚举

  • 通过按位或组合多个开关位
enum Perm { None = 0, Read = 1 << 0, Write = 1 << 1, Exec = 1 << 2 }
const can = Perm.Read | Perm.Write;
1
2

# 注意事项与替代方案

  • 字符串枚举不能反向映射；数字枚举的反向映射仅在运行时存在
  • 枚举在模块边界上是运行时对象，可能影响 tree-shaking；对外 API 推荐使用联合字面量类型：
type StatusL = 'init' | 'loading' | 'done';
