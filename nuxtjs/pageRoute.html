# Nuxt.js 文件路由系统

Nuxt.js 基于文件系统自动生成路由，无需手动配置路由表。pages/ 目录下的文件和目录结构即对应应用的路由结构。

# 路由渲染与识别规则

Nuxt.js 会自动扫描 pages/ 目录，根据文件和目录的名称生成对应的 Vue Router 配置。

# 基本规则

文件路径 生成路由
pages/index.vue /
pages/about.vue /about
pages/user/index.vue /user
pages/user/profile.vue /user/profile

# 示例

<!-- pages/index.vue -->
<template>
  <div>
    <h1>首页</h1>
    <NuxtLink to="/about">关于页</NuxtLink>
  </div>
</template>

# 路由跳转

Nuxt.js 推荐使用 <NuxtLink> 组件进行页面跳转，它是对 Vue Router <router-link> 的封装，支持预加载等优化。

# 声明式跳转

<template>
  <div>
    <!-- 基本跳转 -->
    <NuxtLink to="/about">关于页</NuxtLink>

    <!-- 带参数跳转 -->
    <NuxtLink :to="'/user/' + userId">用户详情</NuxtLink>

    <!-- 命名路由跳转 -->
    <NuxtLink :to="{ name: 'user-id', params: { id: 1 } }"> 用户1 </NuxtLink>

    <!-- 外部链接 -->
    <NuxtLink to="https://nuxt.com" external> Nuxt 官网 </NuxtLink>
  </div>
</template>

# 编程式跳转

<script setup>
const router = useRouter();

function goToAbout() {
  router.push("/about");
}

function goToUser(id) {
  router.push({ name: "user-id", params: { id } });
}

function goBack() {
  router.go(-1);
}
</script>

<template>
  <div>
    <button @click="goToAbout">跳转到关于页</button>
    <button @click="goToUser(5)">跳转到用户5</button>
    <button @click="goBack">返回上一页</button>
  </div>
</template>

# 可选参数路由

使用双方括号 [[]] 定义可选参数。

pages/
└── search/
    └── [[keyword]].vue    → /search/:keyword?   (keyword 可选)
1
2
3
<!-- pages/search/[[keyword]].vue -->
<script setup>
const route = useRoute();
const keyword = route.params.keyword || "";

const searchResults = computed(() => {
  if (!keyword) return [];
  // 模拟搜索
  return [
    { id: 1, title: `关于 "${keyword}" 的结果1` },
    { id: 2, title: `关于 "${keyword}" 的结果2` },
  ];
});
</script>

<template>
  <div>
    <h1>搜索</h1>
    <input v-model="keyword" placeholder="请输入搜索关键词" />
    <p v-if="!keyword">请输入关键词进行搜索</p>
    <ul v-else>
      <li v-for="item in searchResults" :key="item.id">
        {{ item.title }}
      </li>
    </ul>
  </div>
</template>

# 捕获所有路由

使用 [...slug] 匹配任意深度的路径。

pages/
└── docs/
    └── [...slug].vue    → /docs/*   (匹配 /docs/a, /docs/a/b, /docs/a/b/c)
1
2
3
<!-- pages/docs/[...slug].vue -->
<script setup>
const route = useRoute();
// slug 是一个数组，例如 /docs/guide/install → ['guide', 'install']
const slug = route.params.slug;
</script>

<template>
  <div>
    <h1>文档</h1>
    <p>当前路径段: {{ slug.join(" / ") }}</p>
  </div>
</template>

# 路由元信息

可以在页面中使用 definePageMeta 设置路由元信息。

<script setup>
definePageMeta({
  title: "用户详情",
  middleware: "auth",
  layout: "admin",
  keepalive: true,
});
</script>

<template>
  <div>
    <h1>需要认证的页面</h1>
    <p>此页面使用 admin 布局，且会保持存活状态</p>
  </div>
</template>

export default defineNuxtRouteMiddleware((to, from) => {
  const isAuthenticated = useCookie("token").value;

  if (!isAuthenticated) {
    return navigateTo("/login");
  }
});

# 总结

Nuxt.js 的文件路由系统核心要点：

  • 自动路由：pages/ 目录结构即路由，无需手动配置
  • 动态路由：[param] 定义动态参数，[...slug] 捕获所有路径
  • 嵌套路由：父目录下创建同名子目录，使用 <NuxtPage /> 作为子路由出口
  • 路由跳转：推荐使用 <NuxtLink> 组件，支持预加载优化
  • 路由守卫：通过中间件 middleware/ 和 definePageMeta 实现路由级别的权限控制
