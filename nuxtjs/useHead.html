# useHead

useHead 是 Nuxt.js 3 提供的组合式函数，用于在页面或组件中动态设置 <head> 标签内容，如 title、meta、link、script 等。

# 基本用法

在 <script setup> 中直接调用 useHead 即可设置页面头部信息。

<!-- pages/about.vue -->
<script setup>
useHead({
  title: '关于我们',
  meta: [
    { name: 'description', content: '这是关于我们页面的描述' }
  ]
})
</script>

<template>
  <div>
    <h1>关于我们</h1>
  </div>
</template>

# 动态标题

结合响应式数据，可以根据页面状态动态更新标题。

<!-- pages/product/[id].vue -->
<script setup>
const route = useRoute()
const { id } = route.params

const product = ref(null)

const { data } = await useFetch(`/api/product/${id}`)
product.value = data.value

useHead({
  title: computed(() => product.value ? product.value.name : '加载中...'),
  meta: [
    {
      name: 'description',
      content: computed(() => product.value?.description || '')
    }
  ]
})
</script>

<template>
  <div>
    <h1>{{ product?.name }}</h1>
    <p>{{ product?.description }}</p>
  </div>
</template>

# 设置多个 meta 标签

<script setup>
useHead({
  title: 'Nuxt.js 教程',
  meta: [
    { name: 'description', content: '全面的 Nuxt.js 学习指南' },
    { name: 'keywords', content: 'nuxt, vue, ssr, 前端框架' },
    { property: 'og:title', content: 'Nuxt.js 教程' },
    { property: 'og:description', content: '全面的 Nuxt.js 学习指南' },
    { property: 'og:type', content: 'website' },
    { property: 'og:image', content: 'https://example.com/og-image.png' }
  ],
  link: [
    { rel: 'canonical', href: 'https://example.com/nuxt-tutorial' }
  ]
})
</script>

# 引入外部资源

通过 link 和 script 引入外部 CSS 和 JavaScript。

<script setup>
useHead({
  link: [
    {
      rel: 'stylesheet',
      href: 'https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css'
    }
  ],
  script: [
    {
      src: 'https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js',
      defer: true
    },
    {
      src: 'https://example.com/analytics.js',
      async: true
    }
  ]
})
</script>

# 在组件中使用

useHead 不仅可以在页面中使用，也可以在任何组件中调用，会自动合并到最终的 <head> 中。

<!-- components/ProductCard.vue -->
<script setup>
const props = defineProps({
  product: {
    type: Object,
    required: true
  }
})

useHead({
  script: [
    {
      type: 'application/ld+json',
      innerHTML: JSON.stringify({
        '@context': 'https://schema.org',
        '@type': 'Product',
        name: props.product.name,
        description: props.product.description
      })
    }
  ]
})
</script>

<template>
  <div class="product-card">
    <h3>{{ product.name }}</h3>
    <p>{{ product.description }}</p>
  </div>
</template>

# 使用模板参数

通过 titleTemplate 可以设置标题模板，%s 会被替换为当前页面的 title。

<!-- app.vue 或布局文件中设置全局模板 -->
<script setup>
useHead({
  titleTemplate: '%s - 我的网站'
})
</script>

# HTML 属性

可以通过 htmlAttrs 和 bodyAttrs 设置 <html> 和 <body> 标签的属性。

<script setup>
const isDark = ref(false)

useHead({
  htmlAttrs: {
    lang: 'zh-CN',
    class: computed(() => isDark.value ? 'dark' : 'light')
  },
  bodyAttrs: {
    class: 'page-body'
  }
})
</script>

<template>
  <div>
    <button @click="isDark = !isDark">切换主题</button>
  </div>
</template>

# 服务端渲染注意事项

useHead 在服务端和客户端都会执行，确保 SEO 友好。

<script setup>
const route = useRoute()

// 服务端渲染时也能正确设置 title，利于 SEO
useHead({
  title: computed(() => {
    const pageNames = {
      '/': '首页',
      '/about': '关于我们',
      '/contact': '联系我们'
    }
    return pageNames[route.path] || '页面未找到'
  })
})
</script>

# 与 useSeoMeta 结合

Nuxt.js 提供了 useSeoMeta 作为 SEO 相关 meta 的快捷方式，用法更简洁。

<script setup>
useSeoMeta({
  title: 'Nuxt.js 教程',
  description: '全面的 Nuxt.js 学习指南',
  ogTitle: 'Nuxt.js 教程',
  ogDescription: '全面的 Nuxt.js 学习指南',
  ogImage: 'https://example.com/og-image.png',
  ogType: 'website',
  twitterCard: 'summary_large_image',
  twitterTitle: 'Nuxt.js 教程',
  twitterDescription: '全面的 Nuxt.js 学习指南',
  twitterImage: 'https://example.com/og-image.png'
})
</script>

# 总结

  • useHead 在 <script setup> 中直接调用，设置页面 <head> 内容
  • 支持 title、meta、link、script、style、htmlAttrs、bodyAttrs 等全部 HTML 头部元素
  • 支持响应式数据，通过 computed 实现动态更新
  • 页面和组件中均可使用，最终会自动合并
  • 搭配 useSeoMeta 可以更便捷地设置 SEO 相关标签
